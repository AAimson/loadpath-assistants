# Loadpath

Ask ChatGPT for a workout or a program and get a link that opens it in
[Loadpath](https://getloadpath.com), the iPhone strength training app.

ChatGPT writes the plan in Loadpath's own format: lifts by the names in Loadpath's library,
sets and reps, and progression Loadpath runs for you: adding weight when every rep lands,
rep ranges, 5/3/1 training maxes and GZCLP tiers. Weights come from your own history in the
app, so the plan works for any lifter.

The link opens the plan as a preview in Loadpath 2.7 or later, and nothing is saved until
you tap Save. Without the app, it opens a page that shows the plan and how to get Loadpath.
ChatGPT needs to run code to build the link; without it, ChatGPT gives the plan as text
to paste into Train → + → Import from Text.
